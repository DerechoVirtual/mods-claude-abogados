# Carpeta de demostración (todo FICTICIO)

Abre Claude Code en ESTA carpeta para grabar la demo de los mods:

    cd demo
    claude

`config/clientes.json` del plugin apunta a `expedientes/garcia`, `expedientes/lopez` y `expedientes/comunidad-imaginaria` (rutas relativas a esta carpeta): así el Mod 4 puede avisar cuando Claude toca la carpeta de un cliente que no es el activo.

Ningún nombre, importe ni dato de estos archivos corresponde a personas o empresas reales.
