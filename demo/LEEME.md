# Carpeta de demostración (todo FICTICIO)

Expedientes inventados para probar los mods sin tocar asuntos reales. Abre Claude Code en ESTA carpeta:

    cd demo
    claude

En la app de escritorio: pestaña Code y elige esta carpeta como carpeta de trabajo.

Los tres clientes de ejemplo de `mods-abogados` (García, López y Comunidad Calle Imaginaria) apuntan a `expedientes/garcia`, `expedientes/lopez` y `expedientes/comunidad-imaginaria` (rutas relativas a esta carpeta): así el mod «Un color por cliente» puede avisar cuando Claude toca la carpeta de un cliente que no es el activo.

Ningún nombre, importe ni dato de estos archivos corresponde a personas o empresas reales.
